# Support

- **Questions, ideas, "how do I test my agent with this?"**: GitHub Discussions.
- **Bugs in the harness, scorer or leaderboard**: open an issue with the bug form. Include the
  command, exit code and the relevant part of `report.json`.
- **Public scenario proposals**: the scenario issue form, or a PR (see
  [CONTRIBUTING.md](CONTRIBUTING.md#add-a-scenario)).
- **Security vulnerabilities, or anything involving held-out corpus content**: never in public.
  Follow [SECURITY.md](SECURITY.md).

Free support is best effort from a single maintainer, with no response-time commitment.

## Commercial audits

Paid audits of an x402-paying agent or guardrail, run on your own infrastructure: open a
[discussion](https://github.com/x402-redteam/x402-redteam/discussions) and the maintainer will
follow up privately.
